# Sutra Evaluation Dataset

## Purpose

This small manually curated dataset provides a repeatable benchmark for the Sutra multilingual news summarizer. It is intended for academic evaluation of extractive or transformer-based summarization and named entity recognition (NER).

## Coverage

- Languages: English (`en`), Hindi (`hi`), and Marathi (`mr`)
- Articles: 15 total, with 5 articles per language
- Article style: short, fictional news-style reports suitable for local testing
- Sources: all records were written for this dataset; no websites were scraped

Each record contains a unique ID, language code, article text, a human-written reference summary, and manually annotated entities.

## Entity Categories

The annotations use the project entity categories:

- `PERSON`
- `ORGANIZATION`
- `LOCATION`
- `DATE`

Reference summaries and entity annotations are manually written. They are not generated by the Sutra models and should be treated as a small academic evaluation sample, not as a production benchmark.

## Running Evaluation

Install the optional model dependencies, then run the evaluation explicitly from the project root:

```powershell
python evaluation/run_evaluation.py
```

The runner reports ROUGE-1, ROUGE-2, and ROUGE-L for baseline and mT5 summaries, plus precision, recall, and F1 for regex and Indic-NER entities. Results are grouped by language and overall. Use `--json` for machine-readable output.

Transformer model failures are reported as unavailable with missing metrics. The runner never substitutes baseline results for unavailable transformer results.

## File Format

The records are stored in [dataset.json](dataset.json) as a JSON array. Entity objects use `text` and `type` fields so they can be compared with the project's NER output after converting `type` to the internal label representation if needed.
